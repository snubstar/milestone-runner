


The high end concepts are:

**goal**
The goal might be ambiguous, or needed to be clarified, or too general.
With a goal a lot can be done. It can be clarified, assessed for feasibility, etc. broken down in sub-goals, etc.

**ACTIONS**

**document-oriented actions**
  **planning**
  Planning is a document-based action, in which a plan is made for a given goal.
  The plan can be a **roadmap** or specific enough to include more specific implementation steps.

  A plan can be reviewed/corrected, assessed for feasibility, etc.

  **review a document**
  Review a plan is a very important stpe.

**code-oriented actions**

------------------------------------------------------------

- Make a plan.
- Review a plan.
- Nesting of plans, what is the depth.
- Review plans relative to others and job alredy done.
- Design principles.
- Implement a step.
- Review job done for a step.
- Run tests.
